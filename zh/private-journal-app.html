iPhone 上最私密的日记应用

大多数日记应用把你的条目存储在服务器上。大多数 AI 日记应用会把你的私人想法发送给 OpenAI 或它们自己的云端。MirrorNotes 两者都不做。AI 运行在你的 iPhone 上。你的日记文字哪里也不会去。

隐私保证

  • 日记文字从不被传输：没有服务器，没有云端 AI，没有 API 调用
  • 所有 AI 都运行在你 iPhone 的芯片上（通过 CoreML 运行的 Gemma 3），而不是别人的服务器上
  • 无需账户，无需登录：没有什么可以被入侵
  • iCloud 同步在你自己的 Apple ID 下加密：我们无法读取
  • 支持飞行模式：任何功能都不需要联网

为什么大多数「私密」应用其实并不私密

隐私政策会说「我们不出售你的数据」。这和「我们看不到你的数据」是两回事。大多数日记应用会把你的条目存储在他们的服务器上，即使他们承诺不会滥用。当涉及 AI 功能时，你的文字会由云端模型处理，这意味着它会经过互联网，穿过别人的基础设施。

这并不是在批评这些公司的初衷。这是云端 AI 工作方式带来的技术性后果。模型必须先收到你的文字，才能处理它。

MirrorNotes 的隐私是架构层面的。不存在任何会传输你日记文字的代码路径。模型就在你的设备上，直接在你的芯片上读取你的条目。没有什么可以被拦截，没有什么可以被入侵，也没有什么可以被传票要求提供。

隐私在技术上是如何实现的

📱

设备端 AI

Gemma 3 1B 通过 CoreML 运行在你 iPhone 的神经网络引擎上。没有 API 调用，不消耗任何 token，不发送任何数据。

🔒

SwiftData 存储

日记条目本地存储在你设备上的 SwiftData 中。iOS 会对静态数据加密。我们没有你条目的任何数据库。

☁️

iCloud 同步

可选的 iCloud 备份会在你的 Apple 设备之间同步条目。在你自己的 Apple ID 下加密。我们无法访问它。

✈️

离线优先

每一项功能——书写、阅读、搜索、所有 AI 功能——都能在没有网络连接的情况下使用。

常见问题

MirrorNotes 能看到我的日记吗？

不能。条目存储在你设备上的 SwiftData（一个 Apple 框架）中，并可以选择通过你自己的 iCloud 同步。我们没有任何接收日记文字的服务器，没有条目数据库，也没有能力读取你写下的内容。

如果我删除应用会怎样？

本地存储的条目会随应用一起被删除。iCloud 中的副本会保留，直到你从 iCloud 中删除它们——这由你在 iOS 设置中自行控制。我们这边不会保留任何内容。

有隐私政策吗？

有，阅读完整的隐私政策。简而言之：我们不收集日记内容，不出售数据，也不会对你写的内容进行任何分析。

MirrorNotes 是开源的吗？

是的。应用的源代码以 AGPL-3.0 许可证在 GitHub 上公开，你可以阅读处理你日记的代码。你也可以直接验证隐私性：在使用 MirrorNotes 时运行一个网络监控工具，你会看到零个与日记相关的网络请求。
